# てだこボウル 集客用サイト

沖縄県浦添市のボウリング場「てだこボウル」の集客用1ページサイトです。
`index.html` をブラウザで開けばそのまま表示できます（ビルド不要）。

## 中身

- `index.html` … サイト本体（HTML・CSS・JavaScriptをすべて1ファイルに内包）
- `images/` … 掲載写真6枚（商用利用可能なフリー素材を1200px幅に最適化）

## 掲載している情報

- 営業時間・住所・電話番号・駐車場・アクセス
- 料金（平日／土日祝、早朝100円ゲーム、各種パック）※料金表は店頭掲示をもとにした目安
- 施設（36レーン・2フロア、個室レーン10本など）、大会・イベント、よくあるご質問

## 注意

- 写真はイメージです（Googleマップの写真は撮影者の著作物のため使用していません）。
- 料金・営業時間・イベント内容は変更される場合があります。掲載内容は2026年11月時点のものです。
