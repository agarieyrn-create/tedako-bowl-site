# てだこボウル 集客用サイト

沖縄県浦添市のボウリング場「てだこボウル」の集客用1ページサイトです。
`index.html` をブラウザで開けばそのまま表示できます（ビルド不要）。

## 中身

- `index.html` … サイト本体（HTML・CSS・JavaScriptをすべて1ファイルに内包）
- `images/` … 掲載写真6枚（イメージ素材、1200px幅に最適化）

## 掲載している情報

- 営業時間・住所・電話番号・駐車場・アクセス
- 料金（平日／土日祝、土日朝の100円ゲーム、各種パック）※料金表は店頭掲示をもとにした目安
- 施設（36レーン・2フロア、個室レーン10本など）、大会情報の確認先、よくあるご質問

## 実店舗の写真へ差し替えるとき

現在の写真はイメージ素材です。店舗で撮影した写真を使う場合は、掲載許可を確認したうえで、以下のファイル名を保って置き換えてください。ページ内で画像の使い回しがない構成です。

- `images/lane.jpg` … ファーストビューのボウリングレーン
- `images/scene-family.jpg` … 家族向けシーン（ノーガターレーンがあると伝わる写真）
- `images/scene-friends.jpg` … 友人向けシーン
- `images/scene-group.jpg` … 団体・個室レーンのシーン
- `images/balls.jpg` … ボールの貸し出し
- `images/shoes.jpg` … 貸しシューズ

人物が写る写真は、Web掲載の同意を得てから使用してください。Googleマップの写真は撮影者の著作物のため、許可なく転載しないでください。

## 注意

- 写真はイメージです（Googleマップの写真は撮影者の著作物のため使用していません）。
- 料金・営業時間・イベント内容は変更される場合があります。掲載内容は2026年11月時点のものです。
