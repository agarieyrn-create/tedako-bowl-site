# てだこボウル 集客用サイト

沖縄県浦添市のボウリング場「てだこボウル」の集客用1ページサイトです。
`index.html` をブラウザで開けばそのまま表示できます（ビルド不要）。

## 中身

- `index.html` … サイト本体（HTML・CSS・JavaScriptをすべて1ファイルに内包）
- `images/` … 掲載写真6枚（商用利用可能なフリー素材を1200px幅に最適化）

## 掲載している情報

- 営業時間・住所・電話番号・駐車場・アクセス
- 料金（平日／土日祝、早朝100円ゲーム、各種パック）※料金表は店頭掲示をもとにした目安
- 施設（36レーン・2フロア、個室レーン10本など）、大会・イベント、よくあるご質問

## 注意

- 写真はイメージです（Googleマップの写真は撮影者の著作物のため使用していません）。
- 料金・営業時間・イベント内容は変更される場合があります。掲載内容は2026年11月時点のものです。

公開中のページ: https://site-689478affd56400bb480dec831bfdccc.freebuff.page/

## 更新時の確認事項

- 写真はすべてイメージ素材です。実際の施設写真を、権利・撮影対象者の許諾を確認のうえ差し替えてください。
- 料金区分・営業時間・祝日や特別期間の扱い・大会日程・予約方法は店舗に確認してください。構造化データも確認後に同じ内容へ更新してください。
- OGP の URL と画像 URL は現在 README に記載されている公開先を指定しています。公開先を変更する場合は `index.html` の両方を更新してください。
- 元画像の最大幅が 1200px のため、WebP は 800px と 1200px を用意しています。実写真への差し替え時は大きな元画像から 800px と 1600px の画像を作成し、`srcset` の幅も更新してください。
- 店舗の依頼による公式サイトか、制作提案用サンプルかを確認してください。提案用の場合は、公式サイトとの誤認を避ける表示や公開範囲を検討してください。
